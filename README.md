# Lab 6: Components
## Overview
This project will show three different approaches to creating a chatbot.
## Project Goals
By the end of this lab, I will have:
1. A home page that will link to all different approaches
2. A prototype static page that will be the template for the other approaches
3. A chatbot using dom manipulation
4. A chatbot using graceful degradation and then progressive enhancement
## Website Details
My website will support and show off:
- A functioning chatbot
- Be able to talk to this chatbot
- Show off all different versions you can do
- Give multiple options
## Development Approach
This project follows a step-by-step development approach:
1. Giving a prototype of the template of what the chat will look like being static
2. Showing off dom manipulation with the first working chatbot using eliza.js
3. Showing off graceful degradation with second working chatbot
4. Showing off progressive enhancement with the last working chatbot
